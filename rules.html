rules_ctx since api_version 1

The read-only context of a rules call or modifier.

Fields

ParameterPassedDefaultDoc

The faction labels actor belongs to, as a list of strings.

ParameterPassedDefaultDoc
actorpositional or namedThe actor.

memories(subject = None, event = None, since = 0) since api_version 1 feature: combat

Queries combat memories of ctx.actor, newest first; [] when ctx.actor is not a mob.

ParameterPassedDefaultDoc
subjectpositional or namedNoneOptional actor view filter.
eventpositional or namedNoneOptional event name filter.
sincepositional or named0Minimum pulse.

Example

mob("guard", name = "Guard", behaviors = [aggressive(prefer = "grudge")])

def _taunt(ctx):
    ctx.remember(ctx.here("guard"), ctx.actor, "taunt", amount = 10)
    ctx.send(ctx.actor, "mems=%d" % len(ctx.memories(ctx.here("guard"), event = "taunt")))

room("post", name = "Post", desc = "Post.", flags = ["dead_end_ok"],
     commands = {"taunt": _taunt})

Test

w = t.world(seed = 1)
w.spawn(":guard", at = ":post")
p = w.spawn_player("Tess", at = ":post")
t.contains(p.do("taunt"), "mems=1")
for d in w.diagnostics():
    t.fail("%s" % d.message)
