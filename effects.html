Effects and behaviors

Effect primitives

Declarative effects for skill(effect=...), item(use_effect=...) and hooks.

apply_affect(name, duration, stat_deltas = None, flags = [], tick_every = None, on_tick = None, on_expire = None, expire_msg = '', modifiers = {}, sense_deltas = {}, max_vital_deltas = None, resist_deltas = None, applies = None, procs = [], add_tags = [], remove_tags = []) since api_version 1

Attach a timed buff or debuff.

ParameterPassedDefaultDoc
namepositional or namedAffect name; applying the same name again replaces the existing affect.
durationpositional or namedDuration in pulses; None makes an item affect permanent.
stat_deltaspositional or namedNoneStat adjustments while the affect lasts, built with stats(...).
flagspositional or named[]Flags the affect grants, such as 'no_regen'.
tick_everypositional or namedNonePulses between on_tick calls, or None for no ticking.
on_tickpositional or namedNoneTop-level function fn(ctx) called every tick_every pulses.
on_expirepositional or namedNoneTop-level function fn(ctx) called when the affect expires or is removed.
expire_msgpositional or named''Text sent to the target when the affect ends.
modifierspositional or named{}Rules modifiers active while the affect lasts, by modifier point name.
sense_deltaspositional or named{}Sense score changes by channel while the affect lasts.
max_vital_deltaspositional or namedNoneVital maximum adjustments while the affect lasts, built with vitals(...).
resist_deltaspositional or namedNoneDamage resistance adjustments while the affect lasts, built with resists(...).
appliespositional or namedNoneItem affects only: 'worn' or 'carried'.
procs feature: combatpositional or named[]Combat procs that fire during auto-attack swings.
add_tagspositional or named[]Tags a room gains while the affect lasts; a room affect only.
remove_tagspositional or named[]Tags a room loses while the affect lasts; a room affect only.

Example

skill("slow",
    kind = "spell",
    cost = vitals(mana = 4),
    range = "near",
    effect = apply_affect(
        name = "slowed",
        duration = 40,
        stat_deltas = stats(dex = -2),
        expire_msg = "You feel quick again.",
    ),
)

Deal damage.

ParameterPassedDefaultDoc

Example

dispel(name = None, flag = None, all = False, count = None) since api_version 1

Remove the target's affects that match every given criterion. Affects flagged 'intrinsic' are never removed.

ParameterPassedDefaultDoc
namepositional or namedNoneAffect name to remove; a trailing * matches every name with that prefix.
flagpositional or namedNoneA flag, or a list of flags; matches affects carrying any of them.
allpositional or namedFalseTrue to match every affect.
countpositional or namedNoneMost affects to remove, oldest first, or None to remove every match.

Example

# Removes "poison", "poison_strong" and every other affect named poison...
skill("cure", kind = "spell", cost = vitals(mana = 6), target = "ally",
      effect = dispel(name = "poison*"))
# Lifts at most one curse, whatever it is called.
skill("uncurse", kind = "spell", cost = vitals(mana = 8), target = "ally",
      effect = dispel(flag = "curse", count = 1))

summon(label, count = 1, duration = None) since api_version 1

Spawn mobs beside the caster.

ParameterPassedDefaultDoc
labelpositional or namedMob prototype label to spawn.
countpositional or named1Number of mobs to spawn, at least 1.
durationpositional or namedNonePulses before the summoned mobs vanish, or None to keep them.

Behaviors

Built-in mob behaviors for mob(behaviors=[...]).

aggressive(toward = 'players', unless_level_above = None, unless_level_below = None, chance = 100, disposition_below = None, prefer = None, priority = None) since api_version 1 feature: combat

Behavior: attacks matching actors it notices. toward is 'players', 'mobs', 'all' or label patterns.

ParameterPassedDefaultDoc
toward feature: combatpositional or named'players'Who to attack: 'players', 'mobs', 'all', or label patterns such as 'goblin_*'.
unless_level_above feature: levelingpositional or namedNoneSpare actors above this level, or None to attack any level.
unless_level_below feature: levelingpositional or namedNoneSpare actors below this level, or None to attack any level.
chance feature: combatpositional or named100Percent chance of looking for a target on each think, 0 to 100.
disposition_below feature: standingpositional or namedNoneAttack only targets whose disposition is strictly below this threshold (-100..100).
prefer feature: combatpositional or namedNonePlain data passed to the world's target_order; None chooses as described.
priority feature: combatpositional or namedNoneProposal priority; higher wins. None uses the behavior's default.

Example

mob("bandit", vitals = vitals(hp = 20), behaviors = [aggressive(toward = "players", unless_level_above = 5, chance = 50)])

assist(allies, disposition_above = None, prefer = None, priority = None) since api_version 1 feature: combat

Behavior: joins fights alongside allies, given as label patterns such as 'goblin_*'.

ParameterPassedDefaultDoc
allies feature: combatpositional or namedAllies to help, as label patterns such as 'goblin_*'.
disposition_above feature: standingpositional or namedNoneHelp allies and spare opponents whose disposition is strictly above this threshold (-100..100).
prefer feature: combatpositional or namedNonePlain data passed to the world's target_order; None chooses as described.
priority feature: combatpositional or namedNoneProposal priority; higher wins. None uses the behavior's default.

Example

mob("goblin_scout", vitals = vitals(hp = 10))
mob("goblin_chief", vitals = vitals(hp = 30), behaviors = [assist(allies = ["goblin_*"])])

defend(group = True, priority = None) since api_version 1 feature: combat

Behavior: attacks whatever its owner is fighting; with group, whatever the owner's in-room group members are fighting.

ParameterPassedDefaultDoc
group feature: combatpositional or namedTrueAlso defend the owner's in-room group members.
priority feature: combatpositional or namedNoneProposal priority; higher wins. None uses the behavior's default.

Example

# Joins whatever its owner, or the owner's group, is fighting.
mob("guard_dog", vitals = vitals(hp = 15), behaviors = [heel(), defend(group = True)])

flee(below, priority = None) since api_version 1 feature: combat

Behavior: flees when any listed vital is at or below its percentage of its maximum.

ParameterPassedDefaultDoc
below feature: combatpositional or namedPercentages (0..100) by vital, built with vitals(...).
priority feature: combatpositional or namedNoneProposal priority; higher wins. None uses the behavior's default.

Example

mob("hare", vitals = vitals(hp = 6), behaviors = [flee(below = vitals(hp = 50))])

Behavior: follows the first matching actor it meets ('players', 'mobs' or label patterns).

ParameterPassedDefaultDoc
targetpositional or namedWho to follow: 'players', 'mobs', or label patterns.
disposition_above feature: standingpositional or namedNoneFollow only leaders whose disposition is strictly above this threshold (-100..100).
prioritypositional or namedNoneProposal priority; higher wins. None uses the behavior's default.

Example

guard(exit, allies = 'mobs', disposition_above = None) since api_version 1

Behavior: denies an exit to everyone who isn't an ally (default: other mobs) while the guard is present.

ParameterPassedDefaultDoc
exitpositional or namedDirection of the exit to guard.
alliespositional or named'mobs'Who may pass: 'players', 'mobs', 'all', or label patterns.
disposition_above feature: standingpositional or namedNoneActors whose disposition is strictly above this threshold (-100..100) are allowed through.

Example

# Players can't go north while the sentry is here; other mobs can.
mob("sentry", vitals = vitals(hp = 30), behaviors = [sentinel(), guard(exit = "north", allies = "mobs")])

heel(priority = None) since api_version 1

Behavior: follows its owner by the shortest path, however far. Does nothing for a mob without an owner in the world.

ParameterPassedDefaultDoc
prioritypositional or namedNoneProposal priority; higher wins. None uses the behavior's default.

Example

# Idle until the mob has an owner; then it trails the owner anywhere.
mob("tame_hound", vitals = vitals(hp = 15), behaviors = [heel(priority = 40)])

pursue(target, disposition_below = None, priority = None, range = 10) since api_version 1

Behavior: heads for the nearest matching actor within range exits.

ParameterPassedDefaultDoc
targetpositional or namedWho to pursue: 'players', 'mobs', or label patterns.
disposition_below feature: standingpositional or namedNonePursue only targets whose disposition is strictly below this threshold (-100..100).
prioritypositional or namedNoneProposal priority; higher wins. None uses the behavior's default.
rangepositional or named10Exits searched from the mob's room; None searches the whole world.

Example

mob("hound", vitals = vitals(hp = 15), behaviors = [pursue(target = "players")])

retarget(prefer = None, toward = 'players', disposition_below = None, chance = 100, priority = None) since api_version 1 feature: combat

Behavior: while engaged, asks target_order whom to fight and switches to its pick if that is not the primary target.

ParameterPassedDefaultDoc
prefer feature: combatpositional or namedNonePlain data passed to the world's target_order; required.
toward feature: combatpositional or named'players'Non-engaged actors in the room to consider: 'players', 'mobs', 'all', or label patterns.
disposition_below feature: standingpositional or namedNoneConsider only non-engaged targets whose disposition is strictly below this threshold (-100..100).
chance feature: combatpositional or named100Percent chance of asking target_order on each think, 0 to 100.
priority feature: combatpositional or namedNoneProposal priority; higher wins. None uses the behavior's default.

Example

mob("ogre", vitals = vitals(hp = 50), behaviors = [aggressive(prefer = "weakest"), retarget(prefer = "weakest", chance = 50)])
