world(seed = 0, packages = None, rules = None, bubble = False) since api_version 1

A fresh headless world with the given packages (default: this test's package) and the rules package. The `load` argument is spelled `packages`, since load is a Starlark keyword. rules names another rules package to use instead of //rules. bubble=True keeps a reality bubble, so only rooms near players are simulated; by default every room is.

ParameterPassedDefaultDoc
seedpositional or named0Random seed for the world.
packagespositional or namedNonePackages to load, or None for this test's package.
rulespositional or namedNoneRules package label such as //rules_alt, or None for //rules.
bubblepositional or namedFalseTrue to simulate only rooms near players; by default every room is simulated.
