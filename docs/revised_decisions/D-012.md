## Commands (§4.9, §5.2)

### D-012 Standard directions always resolve to movement — `rejected`
Needs revision:
While the behavior that standard directions resolve to movement and non-standard exits resolve to
movement only when present is ratified in principle, exit names must be checked against reserved command
keywords during room definition or zone package loading. If an exit direction or custom exit name
matches a reserved command keyword (such as engine commands, aliases, or global commands), room/package
loading must fail with an error diagnostic indicating that the exit name is a reserved keyword.
*Code:* `CommandRegistry.resolve`, `Direction`, `Declarations.exit`, `Loader.checkCommands`.
