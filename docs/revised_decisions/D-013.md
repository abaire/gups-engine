## Commands (§4.9, §5.2)

### D-013 Engine aliases — `rejected`
Needs revision:
Shorthand aliases for built-in commands should not be statically hardcoded into the engine. Instead:
1. Command aliases must be defined in a configuration file bound to the `World` rather than the engine,
   with a default configuration generated as part of the world template.
2. The configuration must support both standard word aliases (e.g. `l` for `look`, `i`/`inv` for `inventory`)
   and single-character prefixes (e.g. `'` and `"` for `say`, `%` for `cast`).
3. Multiple character prefixes or aliases must be mappable to the same target command (e.g. both `'` and `"` mapping to `say`).
4. Parsing (`parseLine`) and verb resolution (`CommandRegistry`) must consult the active world's alias configuration.
*Code:* `EngineCommands.all`, `parseLine`, `CommandRegistry`, `World`.
