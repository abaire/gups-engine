## Commands (§4.9, §5.2)

### D-011 Lookup precedence and abbreviations — `rejected`
Needs revision:
1. Enforce true unique-prefix resolution for command verbs across engine, global, and
   plugin commands. If an abbreviated verb matches more than one command name (e.g. `cl`
   matching both `clear` and `close`, or `g` matching `gossip`, `get`, and `give`), resolution
   must fail as ambiguous (returning `null` / "Huh?") rather than silently picking the first registered command.
2. Structure item command lookup into layered scopes: search equipped items first, then
   inventory items, and finally items on the ground (tie-breaking by ascending item ID only
   within the same layer). All item layers must continue to resolve before prefix matching of
   engine/global commands. Items inside containers must not grant commands.
*Code:* `CommandRegistry.resolve`.
