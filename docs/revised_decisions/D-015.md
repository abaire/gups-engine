## Commands (§4.9, §5.2)

### D-015 Input from a session without a character — `rejected`
Needs revision:
While routing pre-character session input to `LoginHandler` is accepted, handling for sessions in a world
without a `LoginHandler` (`login == null`) must not leave the connection lingering indefinitely. If a session
has no player and the world has no `LoginHandler`, the engine must output "You are not playing a character.\n"
and immediately close and disconnect the session (`s.sink.close(...)`, `disconnect(s.id)`).
*Code:* `World.handle(ClientInputEvent)`, `Sessions.kt`.
