## Combat (§5.4)

### D-040 Stun and silence are affects — `rejected`
Needs revision:
1. While `stun` and `silence` remain integrated as standard affects with flags, the `silenced` flag must
   not only block spellcasting: it must also prevent verbal commands (`say`, `whisper`, `shout`, `gossip`),
   including verbal interaction with NPCs (such as dialogue branches and quest progression triggered by speaking).
2. Stun and any other timed flags/affects must not blindly overwrite an existing effect with a shorter duration.
   Re-applying an affect or timed flag must only replace the existing state if doing so increases the total
   remaining effect time (i.e. `maxOf(existingRemaining, newDuration)` / only overwrite if `newDuration > remainingDuration`),
   preventing weak or short stuns and debuffs from accidentally or maliciously downgrading a longer effect.
*Code:* `World.applyAffect`, `Effect.Stun`, `CastAction.validate`, `EngineCommands.planSay`, `EngineCommands.planShout`, `EngineCommands.planTell`, `EngineCommands.planWhisper`.
