Test harness

Objects of *_test.star tests: t is the test, w a world, p a player.

diagnostic since api_version 1

A read-only diagnostic entry from w.diagnostics().

Example

Test

w = t.world(seed = 1)
p = w.spawn_player("Tess", at = ":start")
p.do("look")
# A script error in a hook is recorded, not raised: fail on any.
for d in w.diagnostics():
    t.fail("%s:%s %s (%s)" % (d.file, d.line, d.message, d.kind))

Fields

FieldSinceDoc
file1The Starlark file where the error occurred, or None.
hook1The hook, command or timer name, or None.
kind1Diagnostic category, such as 'script_error', 'step_limit' or 'quarantine'.
label1The prototype label involved, or None.
line11-based source line number, or None.
message1Human-readable diagnostic message.
package1The package the diagnostic was charged to, or None.
pulse1Game pulse when the diagnostic was recorded.

p since api_version 1

A test player: its view fields plus do(line), output() and gmcp().

Starlark type player

Example

Test

w = t.world(seed = 1)
p = w.spawn_player("Tess", at = ":start", vitals = vitals(hp = 30))
t.true(p.is_player)
t.contains(p.do("look"), "Start")
t.eq(p.hp, 30)

world(seed = 0, packages = None, rules = None, bubble = False) since api_version 1

A fresh headless world with the given packages (default: this test's package) and the rules package. The `load` argument is spelled `packages`, since load is a Starlark keyword. rules names another rules package to use instead of //rules. bubble=True keeps a reality bubble, so only rooms near players are simulated; by default every room is.

ParameterPassedDefaultDoc
seedpositional or named0Random seed for the world.
packagespositional or namedNonePackages to load, or None for this test's package.
rulespositional or namedNoneRules package label such as //rules_alt, or None for //rules.
bubblepositional or namedFalseTrue to simulate only rooms near players; by default every room is simulated.

ctx(self = None) since api_version 1

A ctx with the verbs of ctx, as a hook owned by self would have it, for setting up state without typing commands. It has no other context fields (actor, target and the rest are None) and labels resolve relative to the test's package. Verbs run at once, outside any pulse; mob actions only queue, so run pulses to let them happen. It stays usable for the rest of the test. deny is an error, and so is passing a function defined in a test file to a verb that keeps it to call later (after, start_task, an affect's on_tick or on_expire).

ParameterPassedDefaultDoc
selfpositional or namedNoneThe ctx's owner, an entity or a label; the world's first room by label when omitted.

Damages one vital of an actor by amount, or by pct of that vital's maximum. Fires on_damage; death is processed at once.

Queues the results of later rolls: each rng.int (and so rng.chance, and every engine chance such as a proc's, loot's or wander's) takes the next queued int, before the seeded stream resumes. A forced int outside the roll's range is an error.
