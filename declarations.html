global_command since api_version 1

Registers a command available everywhere. lib and rules packages only.

ParameterTypePassedRequiredDefaultAllowed valuesDoc
namestrpositional or keywordyesCommand verb players type.
fnfunctionpositional or keywordyesTop-level handler function fn(ctx).
lanestrpositional or keywordno'fast'fast, tickExecution lane: 'fast' (immediate) or 'tick' (queued on the actor).

Example

def _pulse(ctx):
    ctx.send(ctx.actor, "It is pulse %d." % ctx.pulse)

# Only lib and rules packages may register global commands.
global_command("pulse", _pulse, lane = "fast")

Test

w = t.world(seed = 1)
p = w.spawn_player("Tess", at = ":start")

global_hook since api_version 1

Registers a hook that fires for every actor, wherever it is. lib and rules packages only.

ParameterTypePassedRequiredDefaultAllowed valuesDoc

fnfunctionpositional or keywordyesTop-level handler function fn(ctx).

def _step(ctx):

DAMAGE since api_version 1

A struct of the world's declared damage types, such as DAMAGE.fire; a misspelling fails at that line.

Type struct, value struct()

Example

# A misspelling such as DAMAGE.fier fails at that line, with a suggestion.
item("flame_tongue", kind = "melee", wield = "wield", dice = "1d6",
     damage_type = DAMAGE.fire)

Test

w = t.world(seed = 1)
sword = w.spawn(":flame_tongue", at = ":start")
t.eq(sword.damage_type, "fire")
